# Screenshots

Put project screenshots in this folder using these file names (PNG recommended):

| File | What to capture |
|------|-----------------|
| `01-home.png` | Homepage with QR code |
| `02-scanner.png` | Customer scanner camera page |
| `03-catalog.png` | Public product catalog |
| `04-login.png` | Admin login (demo account button visible) |
| `05-products.png` | Admin → Manage Products |
| `06-ai-settings.png` | Admin → AI Settings |

Tips:
- Use a desktop browser at ~1280px width for consistent README layout.
- For the scanner, use a phone screenshot if the camera UI looks better on mobile.
- Do not include real API keys in screenshots.
